\# Supermarket Sales Analysis Project



Hey there! This is my project repository for the Supermarket Sales Analysis internship task. In this project, I took a dataset of 500 supermarket transactions and ran a complete exploratory data analysis (EDA) using Python to find out what's really driving sales.



\## What's in here?

\- \*\*Python Code:\*\* Cleaned up and organized inside a Jupyter Notebook.

\- \*\*Analysis Scope:\*\* Looked into top-selling products, branch performance across different cities, customer spending habits (Members vs. Normal customers), and preferred payment methods.

\- \*\*Visualizations:\*\* Generated charts using Matplotlib and Seaborn to spot trends easily.



\## Tech Stack

\- \*\*Language:\*\* Python 3

\- \*\*Libraries:\*\* Pandas, NumPy, Matplotlib, Seaborn

\- \*\*Environment:\*\* Jupyter Notebook
